# 常见问题与故障判断

| 现象 | 检查与处理 | 不能直接下的结论 |
|---|---|---|
| Python / pip 找不到 | py -0p 确认 3.11+，使用本项目 python -m pip | 不混用其他项目环境 |
| 找不到 Chrome | x_doctor.py；检查 X_WORKBENCH_CHROME 完整路径 | Playwright 包不等于 Chrome |
| 8766 占用 | 检查已有服务，不重复启动；独立目录另选端口 | 不授权杀其他 Python/Chrome |
| 401/403、登录、验证码 | 停止账号请求，正常登录/人工核验保护 | 不换账号、清保护或提速绕过 |
| 429、剩余额度、reset | 保存检查点，遵守服务端 reset 和退避 | 合法等待不等于卡死 |
| 404 | 核对当前查询/游标和证据，按有限复核规则处理 | 不是没帖子，也不必然是封号 |
| pagination_not_triggered | 未取得匹配响应，检查触发、浏览器与日志，保留 cursor | 不等于成功空尾页 |
| 无新增 / 重复 cursor | 看解析、日期排除、重复 ID、原始末页 | 不能单独视为到底 |
| 40条或几千条后停止 | 看限额、技术停止、结束验收 | 条数不证明完整，也不直接证明漏抓 |
| 天数进展少 | 分开看落盘增量、日期/页码、已核验末端 | 不能按每天固定耗时估算 |
| SQLite 比 JSON 多 | 确认存储后端，统一读取权威版本 | 不删库回退旧 JSON |
| 磁盘满/保存失败 | 停止写入、保留原文件，腾空间后核验 | 保存错误不是网络错误 |
| 搜到了但正文无词 | 分开统计原文、引用/转发、命中，保留复核集 | 不直接认定无关 |
| 两次 ID 不一致 | 固定查询/时区/排序/账号，保存响应，比较交差集 | 不保证 X 不同时间返回一致集合 |

## 什么才算到底

成功响应结束或规范三次空尾页须有原始证据。HTTP 200、进程退出、finalized 或队列空都不够。详见 SEARCH_STATUS_RULES.md。旧记录缺证据就保留缺证据，不事后编造；一个日期查询对照不能推广到所有日期。

## 更新后怎么还没明显更快

当前默认仍由 Chrome 发起请求。减少重复扫描、写盘和核验只减少局部开销，不能取消服务器等待。timings.json 区分 request_wait、rate_limit_sleep、pacing_sleep、parse、checkpoint_write；嵌套阶段看 self_seconds，不直接相加 inclusive seconds。

离线 SQLite 基准不含网页、网络和账号限流，不能称整体提速十倍。HTTP 路线仍待真实速度和稳定性验收，不用于自动替换现有任务。

## 反馈最小信息

提供版本号、系统/Python/Chrome 版本、复现步骤、任务类型、停止原因和脱敏短错误。自检不证明登录。不要上传 outputs/、tmp/、整个日志目录、数据库、Cookie、Authorization 或密码；疑似泄密看 SECURITY.md。
